Move Zeros

Given an integer array, move all the zeros to the end of the array while maintaining the relative order of the non-zero elements.

Modify the array in-place.

Example 1
Input:
[0, 1, 0, 3, 12]

Output:
[1, 3, 12, 0, 0]


Example 2
Input:
[1, 2, 3]

Output:
[1, 2, 3]


Example 3
Input:
[0, 0, 0, 1]

Output:
[1, 0, 0, 0]


Example 4
Input:
[0]

Output:
[0]


Constraints

Modify the array in-place.
Preserve the relative order of all non-zero elements.
Do not create another array.


Expected Complexity

Time Complexity: O(n)
Space Complexity: O(1)
