Merge Two Sorted Arrays

You are given two sorted integer arrays, nums1 and nums2.

Merge nums2 into nums1 so that nums1 becomes a single sorted array.

The first array, nums1, has enough extra space at the end to hold all elements from nums2.

Modify nums1 in-place.


Example 1

Input:
nums1 = [1, 2, 3, 0, 0, 0]
m = 3

nums2 = [2, 5, 6]
n = 3

Output:
[1, 2, 2, 3, 5, 6]


Example 2

Input:
nums1 = [1]
m = 1

nums2 = []
n = 0

Output:
[1]


Example 3

Input:
nums1 = [0]
m = 0

nums2 = [1]
n = 1

Output:
[1]


Constraints

Both arrays are sorted in non-decreasing order.
Modify nums1 in-place.
Do not allocate another array.


Expected Complexity

Time Complexity: O(m + n)
Space Complexity: O(1)
